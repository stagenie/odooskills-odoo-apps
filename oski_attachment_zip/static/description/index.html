Pièces jointes en archive

Tous les fichiers d'une fiche — ou de plusieurs — en un seul ZIP.

Odoo 19 sait zipper les fichiers d'un message du fil de discussion. Personne ne range ses documents ainsi : une commande porte le bon signé dans un message, le plan dans un autre, le relevé dans la boîte à pièces jointes. Les envoyer au bureau d'études demande alors autant de téléchargements que de fichiers, puis autant de pièces jointes dans le courriel.

Ce que ça apporte

  • 📦 Une entrée dans le menu d'actions — « Télécharger les pièces jointes (ZIP) », sur la fiche comme sur une sélection dans la liste.
  • 🗂️ Un dossier par fiche quand la sélection en compte plusieurs, et les doublons de nom numérotés.
  • 🔒 Vos droits, rien de plus — les fichiers se lisent avec les droits de qui les demande ; les pièces d'une fiche illisible ne partent pas dans l'archive.
  • ⚙️ Modèle par modèle — vous choisissez où l'entrée apparaît, d'un interrupteur.

Aperçus réels

1. Là où on en a besoin

L'entrée prend place dans le menu d'actions du devis, au milieu de celles d'Odoo. Un clic, un fichier.

2. Vous décidez où

Trois modèles activés ici : le devis, le contact et la tâche. Les modèles abstraits et les assistants ne sont pas proposés — ils n'ont pas de fiche, donc jamais de pièce jointe.

Pourquoi l'adopter

  • Un nom de fichier ne devient jamais un chemin : une pièce nommée ../../etc/passwd écrirait hors de son dossier chez qui décompresse l'archive.
  • Les valeurs de champs binaires — un logo, une photo — et les pièces servies par une URL sont écartées : les premières ne sont pas des pièces jointes, les secondes n'ont rien à archiver.
  • Deux garde-fous : 200 fiches par téléchargement, et un poids maximal réglable. Le refus s'affiche dans une boîte de dialogue, jamais dans une page d'erreur du navigateur.
