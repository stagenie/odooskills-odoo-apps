Attachments as ZIP

All the files of a record — or of several — in a single ZIP.

Odoo 20 can zip the files of one message in the chatter. Nobody files their documents that way: an order carries the signed delivery slip in one message, the drawing in another, the statement in the attachment box. Sending them to the engineering office then takes as many downloads as there are files, and as many attachments in the email.

What it adds

  • 📦 An entry in the Actions menu — "Download attachments (ZIP)", on the record as well as on a selection in the list.
  • 🗂️ One folder per record when the selection holds several, and duplicate file names numbered.
  • 🔒 Your access rights, nothing more — files are read with the rights of whoever requests them; attachments of a record they cannot read stay out of the archive.
  • ⚙️ Model by model — you choose where the entry appears, with a toggle.

Why install it

  • A file name never becomes a path: an attachment named ../../etc/passwd would otherwise write outside its folder for whoever extracts the archive.
  • Binary field values — a logo, a photo — and attachments served by a URL are left out: the former are not attachments, the latter have nothing to archive.
  • Two safeguards: 200 records per download, and an adjustable maximum size. A refusal shows in a dialog box, never in a browser error page.
  • Open source module, LGPL-3 license — no subscription, no external dependency.
