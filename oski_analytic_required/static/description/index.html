Mandatory Analytic by Journal

The criterion Odoo lacks — the journal — and the check before posting.

Odoo can already make analytic mandatory: analytic plan applicability requires it by business domain, by account prefix and by product category. Two things are missing. The journal, which is how most accounting firms actually think — everything going through purchases is distributed, the rest is not. And the timing: the core check only speaks up at posting, when data entry is finished and the screen shows an error instead of a result.

What it adds

  • 📒 One rule per journal, which can be restricted to a list of account prefixes — or to all income and expense accounts of the journal if the field is left empty.
  • 🔍 An "Entries Without Analytic" screen that lists, among drafts, the lines that will block at posting.
  • 🛑 Refusal at posting, so nothing slips through when nobody has looked at the control screen.
  • 🏢 One rule per company, carried by the journal itself.

Why install it

  • Counterpart lines — receivable and payable accounts — and tax lines are excluded by default: they balance the entry, they neither consume nor produce anything.
  • The check only covers drafts: a posted entry no longer blocks anything, and the screen stays a readable size.
  • The indicator is not stored in the database: the rule can change at any time, and a frozen value would go stale with nothing to refresh it.
  • Open source module, LGPL-3 license — it complements the core analytic plan applicability, it does not replace it.
