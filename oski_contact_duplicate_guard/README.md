# OdooSkills — Anti-doublon Contacts

Avertit lorsqu'un contact a le même **email** ou le même **téléphone** qu'un
contact existant. Détection non bloquante : un bandeau affiche un lien vers le
doublon possible. Activable par type depuis **Réglages**.

- **Dépendances** : `contacts`, `base_setup`
