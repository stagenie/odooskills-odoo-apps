Scheduled Action Monitor

Every run: duration, success, error, and the history that goes with it.

Odoo keeps the date of a scheduled action's last run in lastcall, and the number of consecutive failures in failure_count. Neither appears in any view. An action that fails every night — customer reminders, synchronization, stock computation — therefore only shows up in the server log, if someone thinks to open it.

What it adds

  • ⏱️ Every run recorded — start, duration to the millisecond, success or failure, full error message.
  • 🔴 Failures survive the failure — the log is written on a separate transaction, because the action's own transaction is rolled back when it fails. The failure is precisely what must be kept.
  • 📈 Duration becomes data — the column totals up, and slow actions are spotted before they turn into an incident.
  • 🧹 Automatic cleanup — runs older than 30 days go away with Odoo's cleanup; the delay is set by a system parameter.

Why install it

  • The log can never make a successful action fail: a write failure goes to the server log, and the action completes.
  • No configuration: install the module and the first action that runs is already recorded.
  • Open source module, LGPL-3 license — no subscription, no external dependency.
