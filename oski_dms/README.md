# Documents — GED (oski_dms)

GED Odoo 19 Community : espaces cloisonnés, documents enveloppant `ir.attachment`,
versionning, rattachement métier, droits par espace.

## Fonctionnalités
- Espaces hiérarchiques avec droits lecture/écriture/gestion par groupe.
- Documents = métadonnées + pièce jointe (aucun silo binaire).
- Versionning avec restauration.
- Rattachement d'un document à tout enregistrement métier.
- « Classer dans la GED » depuis une pièce jointe existante (sans copie).
- Recherche par espace, étiquette, type, propriétaire, date.
