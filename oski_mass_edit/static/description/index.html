Édition en masse

Modifiez un champ sur toute une sélection depuis la vue liste, sans ouvrir chaque fiche.

Corriger la même erreur sur deux cents contacts, poser un vendeur sur tout un lot de commandes, vider un champ devenu obsolète : Odoo demande d'ouvrir chaque fiche, une par une. La seule alternative native est l'export, la retouche dans un tableur, puis le réimport — trois occasions de se tromper pour une correction d'une seconde.

Ce que ça apporte

  • ✏️ Un champ, toute la sélection — cochez vos lignes, ouvrez « Édition en masse » dans le menu Actions, choisissez le champ et la valeur.
  • 🧩 Sur le modèle de votre choix — un administrateur déclare une fois les modèles concernés ; l'entrée apparaît alors dans leur vue liste, sans toucher aux vues.
  • 🔤 Tous les types courants — texte, texte long, HTML, sélection, entier, décimal, monétaire, booléen, date, date-heure et relation simple.
  • 🧹 Vider aussi bien que remplir — l'opération « Vider le champ » remet à blanc sans passer par une valeur bidon.
  • 🔒 Vos droits s'appliquent — l'écriture passe par les droits d'accès et les règles d'enregistrement de l'utilisateur courant. Le module n'emploie jamais sudo().

Aperçus réels

1. L'entrée s'ajoute au menu Actions de la liste

Trois contacts cochés : « Édition en masse » prend place parmi les actions natives d'Odoo (Export, Dupliquer, Archiver, Supprimer), sans rien déplacer.

2. L'assistant, réduit à l'essentiel

Le modèle et le nombre d'enregistrements retenus sont rappelés en clair ; le champ se choisit dans la liste des champs inscriptibles du modèle, ici « Reference » sur trois contacts.

3. Les modèles ouverts, en un écran

Un administrateur ajoute ou retire un modèle d'une ligne. Le désactiver retire l'entrée du menu Actions sans perdre la configuration.

Pourquoi l'adopter

  • Une correction de masse redevient une correction, au lieu d'un export suivi d'un réimport.
  • Les types non gérés sont refusés par un message explicite plutôt que convertis approximativement : aucune valeur fausse n'est posée sur mille enregistrements.
