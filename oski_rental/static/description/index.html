Resource Rental

Rent out vehicles, rooms, machinery or equipment — booking, pickup/return and invoicing in a single flow.

Odoo Community does not handle rentals: sales orders get repurposed, availability lives in a spreadsheet, and nothing prevents booking the same resource twice on the same dates. Nobody knows what goes out today, what must come back tomorrow, or which deposit is still to be returned.

What it adds

  • 📦 Fleet of individual resources — describe each asset (vehicle, room, machine, equipment) by category, with its hourly / daily / weekly / monthly price grid.
  • 📅 Booking without double-booking — overlapping dates on the same resource are blocked automatically; unavailability periods (maintenance, breakdown) are set by hand.
  • 🔁 Clear pickup → return flow — quotation, reserved, ongoing, returned, invoiced: each rental follows a clean cycle with a condition report at pickup and at return.
  • 💰 Deposit & invoicing — deposit tracking and customer invoice generation (account.move) directly from the rental.
  • ⏰ Late return alerts — a scheduled action spots overdue returns so you can follow up without watching a spreadsheet.

Why install it

  • Real rental management on Odoo Community, without repurposing Sales or switching editions.
  • Generic: the same module covers renting vehicles, rooms, machinery or equipment.
  • Double-booking becomes impossible: no more booking conflicts discovered on pickup day.
