Bulk EAN13 Barcodes

Assign valid EAN13 codes to every product that has none, in one go.

Odoo can validate a barcode and compute its check digit; it cannot generate one. A catalog of a thousand items without codes is therefore filled in by hand, one product after another, with all the typos that implies — and a wrong code only shows up when the scanner rejects the label, at receipt or at the checkout.

What it adds

  • 🔢 Valid EAN13 codes, check digit included — never a number that will fail at the scanner.
  • 🎯 On the selection, from the product or variant list, or on all those that have no code yet.
  • 🔒 An adjustable prefix, by default in the 20-29 range that the standard reserves for a company's internal use.
  • 📋 The count of products concerned shown before acting, and the list of products served shown after.

Why install it

  • Products that already carry a code are never touched: overwriting a code would break the labels already printed and the scanners that read them.
  • Numbers already taken in the range are skipped, including those that came from an import — two products can never end up with the same code.
  • The default prefix starts with 2: departing from it would produce codes resembling another manufacturer's.
  • Open source module, LGPL-3 license — it only depends on products, without requiring Inventory or Point of Sale.
