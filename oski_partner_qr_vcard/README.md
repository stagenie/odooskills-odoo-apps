# OdooSkills — QR vCard Contact

Ajoute un onglet **QR vCard** sur chaque fiche contact. Le code QR encode la fiche
au format vCard 3.0 (nom, société, fonction, email, téléphone, mobile, site web).
Scanné avec un smartphone, il ajoute le contact au carnet d'adresses sans saisie.

- **Dépendances** : `contacts`, lib Python `qrcode`
