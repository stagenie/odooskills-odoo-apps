Couleur de lignes de liste

Surlignez vos commandes urgentes, vos factures en retard ou vos articles critiques — sans toucher une seule ligne de code.

Dans Odoo, colorer une ligne de liste nécessite d'éditer du XML et de connaître la syntaxe des attributs decoration-* — une tâche réservée aux développeurs. Résultat : les équipes opérationnelles voient des listes uniformes et doivent ouvrir chaque enregistrement pour distinguer les urgences des cas normaux. Le tri ne suffit pas : il faut une lecture instantanée de l'état à la couleur.

Ce que ça apporte

  • 🎨 Règles visuelles sans code — définissez une condition Python simple (state == 'done', amount_total > 1000) et choisissez la couleur : bleu, vert, orange, rouge ou gris.
  • ⚡ Application instantanée sur n'importe quel modèle — ventes, achats, factures, stock, projets… chaque liste Odoo est configurable depuis une interface unique, sans modifier les vues XML existantes.
  • 🔁 Vue héritée générée et gérée automatiquement — à la sauvegarde d'une règle, le module crée (ou met à jour) la vue d'héritage correspondante ; à la suppression, elle disparaît proprement.
  • ✅ Activation/désactivation à la volée — basculez une règle sans la supprimer grâce au bouton toggle, idéal pour les colorisations saisonnières ou les campagnes ponctuelles.
  • 📊 Règles ordonnées par séquence — glissez-déposez l'ordre des règles pour contrôler la priorité quand plusieurs conditions s'appliquent au même modèle.

Pourquoi l'adopter

  • Économisez un aller-retour développeur pour chaque demande de mise en couleur — configurez vous-même en 30 secondes depuis Paramètres.
  • Réduisez les erreurs de traitement : les équipes repèrent visuellement les enregistrements à traiter avant même d'ouvrir un filtre.
  • Aucune dépendance extérieure — le module utilise uniquement le mécanisme natif decoration-* d'Odoo, garanti compatible avec toutes les vues liste de la plateforme.
  • Module gratuit — fonctionne en Community et Enterprise sans aucun abonnement supplémentaire.
