# OdooSkills — Couleur de lignes de liste

Colorez les lignes des vues liste selon des règles **sans code** : choisissez un
modèle, une condition (expression Python, ex. `state == 'done'`) et une couleur.
Le module génère une vue liste héritée appliquant la décoration Bootstrap.
