# Abonnements — Oski

Facturation récurrente d'abonnements pour Odoo 19 **Community**.

## Fonctionnalités

- Abonnements avec cycle de vie : brouillon → en cours → suspendu → résilié.
- Plans de facturation réutilisables (jour/semaine/mois/année + intervalle).
- Cron quotidien : génère les factures à échéance (facturation d'avance).
- Option de postage automatique des factures par plan.
- MRR (revenu mensuel récurrent) normalisé, vues pivot et graphique.
- Fin d'engagement avec clôture automatique.

## Dépendances

`sale`, `account` (Odoo CE). Aucun module externe.

## Add-ons (suite OdooSkills)

Paiement tokenisé, portail client, renouvellement, tableau de bord churn —
modules pro séparés.
