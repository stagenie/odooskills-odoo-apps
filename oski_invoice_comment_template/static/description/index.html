Modèles de remarques de facture

Bibliothèque de remarques réutilisables insérées dans les conditions des factures et leur PDF.

Pénalités de retard, escompte, mentions légales : les mêmes remarques reviennent sur toutes les factures, et chacun les retape à sa façon. Ce module crée une bibliothèque de remarques validées une fois pour toutes, insérables en un clic sur la facture — et donc sur son PDF.

Fonctionnalités

  • Modèles de remarques en HTML riche (gras, listes, mentions légales…).
  • Menu de configuration dédié : Comptabilité → Configuration → Modèles de remarques.
  • Champ « Modèle de remarque » sur la facture : la sélection remplit les conditions (narration).
  • La remarque apparaît nativement dans le PDF de la facture — aucun rapport modifié.
  • Le texte reste éditable au cas par cas après insertion.

Grandes opérations

1. Constituer la bibliothèque

Créez vos remarques types une seule fois : pénalités B2B, escompte, TVA sur les débits…

2. Appliquer un modèle sur la facture

Sur la facture, choisissez le modèle : les conditions se remplissent automatiquement, prêtes à ajuster si besoin.

3. Le PDF reprend la remarque

La remarque est imprimée en pied de facture, sans configuration de rapport.

Installation

  1. Décompresser l'archive dans votre addons_path.
  2. Mettre à jour la liste des applications puis installer Modèles de remarques de facture.
