Garde-fou de suppression

Interdisez la suppression modèle par modèle, réservez-la à quelques groupes, et gardez la trace de chaque effacement.

Une suppression ne laisse rien derrière elle : l'enregistrement disparaît, et son chatter avec lui. Odoo ne propose qu'un droit global par modèle, accordé ou refusé une fois pour toutes dans les droits d'accès — sans exception possible, sans message d'explication, et sans le moindre registre de ce qui a été effacé.

Ce que ça apporte

  • 🛡️ Fermer modèle par modèle — désignez les modèles à protéger : commandes, contacts, pièces comptables, ce que vous décidez.
  • 🔑 Ouvrir l'exception à qui vous voulez — les groupes désignés gardent le droit de supprimer. Aucun groupe désigné signifie : personne.
  • 💬 Expliquer le refus — le message affiché est le vôtre (« Archivez plutôt que de supprimer »), pas une erreur technique.
  • 📓 Journaliser sans interdire — le mode « Autoriser, mais journaliser » laisse la porte ouverte et prend la trace : modèle, identifiant, nom affiché, auteur, date.
  • 🔧 La maintenance n'est jamais bloquée — installations, mises à jour, désinstallations et tâches planifiées traversent le garde-fou : il protège l'interface, pas le serveur.

Aperçus réels

1. Deux modèles, deux régimes

Les contacts restent supprimables, mais chaque effacement est inscrit ; les étiquettes de contact, elles, sont fermées à tout le monde.

2. Le refus, tel que l'utilisateur le lit

Un administrateur tente de supprimer une étiquette : la suppression est arrêtée et le message est celui qui a été écrit dans la règle. Le garde-fou ne fait pas d'exception pour l'administrateur.

3. Ce qui a réellement disparu

Trois contacts effacés, avec leur identifiant et leur nom au moment de la suppression — les deux seules informations qu'on ne peut plus retrouver après coup.

Pourquoi l'adopter

  • Le nom et l'identifiant sont capturés avant la suppression : après, plus rien ne permet de les reconstituer.
  • Aucun réglage global à changer : le garde-fou s'ajoute par-dessus vos droits d'accès existants, sans les redéfinir.
